# To-Do App

A lightweight to-do list built with plain HTML, CSS, and JavaScript. Add tasks, edit them, or remove them directly in your browser—no frameworks or installation required.

## Features

- Add tasks to your list
- Update an existing task
- Delete tasks you no longer need
- Simple, responsive browser-based interface
- Preloaded example tasks to try

## Getting started

1. Clone or download this repository.
2. Open `index .html` in a web browser.
3. Enter a task and select **Add Task**.

You can also serve the project with any static web server. There is no build step or dependency installation.

## How to use

- **Add:** Type a task in the input and click **Add Task**.
- **Update:** Click **Update** beside a task, edit its text in the input, and click the button to save.
- **Delete:** Click **Delete** beside a task to remove it.

Tasks are kept in the current page only. Reloading the page resets the list to the example tasks.
